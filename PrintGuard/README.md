# PrintGuard — 打印过程完整性监测系统

针对承重零件工业 3D 打印的**切片指令篡改检测**:攻击者篡改下发给打印机的
G-code,在零件内部留下隐藏空洞、改变填充方向或降低密度——外观与外形尺寸
完全正常,但强度大幅下降。PrintGuard 在打印过程中同步采集物理传感信号,
与原始设计应有的物理过程**逐层比对**,发现内部结构被篡改立即停机。

## 工作原理

```
原始切片文件 ──► 参考过程模型(每层应有:挤出量/耗时/填充方向指纹/温度/声强)
                      │
打印机 ──► 步进脉冲(E/XY/Z)──┐
         ──► 喷嘴温度 ────────┼─► 逐层特征提取 ─► z 标准化 ─► 每特征 CUSUM ─► 超阈值即停机
         ──► 打印声音 ────────┘      (O(1)/样本, 15 ns)
```

- **步进脉冲**重建实际挤出量与运动轨迹(独立于被篡改的指令流本身);
- **声学方向谱**(振幅加权 cos²θ)是填充方向的指纹,方向旋转必被听见;
- **喷嘴温度**捕捉缓慢降温型篡改(层间结合强度攻击);
- **CUSUM 序贯累积**把分散在几十层里、单层淹没在噪声中的细微偏差累积成
  显著证据——这是对抗"细微且分散"篡改的关键;
- 阈值 H 由干净打印自动标定(两阶段:先估 σ,再取 CUSUM 峰值分布),
  把正常抖动与误差变成检测器的已知参数而不是误报源;
- 传感延迟(温度 0.8 s、声学 0.05 s)在层粒度特征聚合下自然吸收,
  层边界由 Z 轴步进脉冲对齐。

## 使用

```bash
cd PrintGuard
dotnet build

# 生成参考零件 G-code(实际部署时替换为客户的切片文件)
dotnet run -- gen -o part.gcode

# 红队工具:生成隐蔽篡改版 G-code(外壳/尺寸不变,仅改内部)
dotnet run -- tamper void      -i part.gcode -o evil.gcode --start 60
dotnet run -- tamper rotate    -i part.gcode -o evil.gcode
#   类型: void / rotate / density / microskip / tempdrift / feed

# 实时监测演示(异步流水线:采集线程 → Channel → 监测线程)
dotnet run -- monitor density

# 完整基准实验:自动标定 + 六类篡改 × 30 次 + 100 次干净打印 → report.md
dotnet run -- bench -o report.md
```

## 验证结果(详见 report.md)

| 篡改类型 | 检出层数(中位) | 检出率 |
|---|---|---|
| 隐藏空洞 Φ16mm × 10 层 | 2 层 | 30/30 |
| 填充方向旋转 90° | 1 层 | 30/30 |
| 填充密度稀释 5%/层 | 5 层 | 30/30 |
| 微跳过 2.5%/层(最细微) | 8 层 | 29/30 + 1 提前误停 |
| 温度渐降 4°C/20 层 | 11 层 | 30/30 |
| 填充速度 ×1.35 | 1 层 | 30/30 |

误停机率 **1%**(100 次干净打印,95% CI ±2%);监测开销 15 ns/样本,
100 Hz 采样下 CPU 占用 ~0.0001%,不拖慢打印。

## 部署说明

- `GCode.Parse` 支持常见切片器输出(G0/G1/G92/M82/M83/M104/M109,
  `;LAYER:` 注释可选,按 Z 变化自动分层);
- 实际接入时,把 `SensorSimulator` 替换为真实采集回调(步进脉冲 GPIO
  计数、热电偶、麦克风),`Monitor.Push` 接口不变;
- 每台机器/每种材料正式投产前跑若干次干净打印重新标定 σ 与 H 即可;
- `Monitor.Alarm` 事件直接接打印机急停(M112 / 继电器)。

## 代码结构

| 文件 | 职责 |
|---|---|
| `src/GCode.cs` | 指令模型、解析/输出、参考零件生成器 |
| `src/Sim.cs` | 参考过程模型、传感器仿真(噪声/延迟)、在线监测器(CUSUM) |
| `src/Tamper.cs` | 六类隐蔽篡改指令生成器(红队工具) |
| `src/Bench.cs` | 标定 + 检出层数/误停机率基准实验 |
| `Program.cs` | CLI:gen / tamper / monitor / bench |
